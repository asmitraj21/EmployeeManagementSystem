# Employee Management System

## Project Description

This is a console-based Employee Management System developed in Core Java.

The application allows the user to:

- Add Employee
- View All Employees
- Search Employee
- Update Employee
- Delete Employee

The project uses Java OOP concepts and ArrayList to store employee records.

## Technologies Used

- Java
- VS Code
- ArrayList
- Scanner
- Object-Oriented Programming

## Program Flow

1. The program starts by displaying the main menu.
2. The user selects an option.
3. Based on the selected option:
   - Add Employee
   - View Employees
   - Search Employee
   - Update Employee
   - Delete Employee
4. The menu is displayed again.
5. The program ends when the user selects Exit.
